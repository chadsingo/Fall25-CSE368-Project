Fill assignemnts and lectures in in pdf formats.
run cd src/utils    then   python process_all_materials.py
app.py can then be run and start taking post requests.

## Loading the Extension (Firefox)
<ol>
	<li>Navigate to about:debugging</li>
	<li>Click "This Firefox" in the top left</li>
	<li>Click "Load Temporary Add-on"</li>
	<li>Select any file in the "extensions" directory</li>
</ol>

## Loading the Extension (Chrome)
<ol>
	<li>Navigate to chrome://extensions/</li>
	<li>Enable "Developer mode" in the top right</li>
	<li>Click "Load unpacked" in the top left</li>
	<li>Select the "extensions" directory</li>
</ol>
